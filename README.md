# Sleepo Recorder

Installers of Sleepo Recorder, the raid recorder of the Sleepo guild, for World of Warcraft TBC Anniversary and WoW Forever (Windows).

Download the latest version from the [releases page](https://github.com/Extazya/sleepo-recorder-releases/releases/latest), or from [sleepo.cc/recorder](https://sleepo.cc/recorder/). The app updates itself afterwards.

Sleepo Recorder is a fork of [Warcraft Recorder](https://github.com/aza547/wow-recorder) by Alex K, licensed under Creative Commons Attribution-NonCommercial. It is distributed free of charge and is not affiliated with the original project.
